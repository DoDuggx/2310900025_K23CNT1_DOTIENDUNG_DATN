# Đồ án tốt nghiệp – NovaMart

Website kinh doanh thiết bị công nghệ tích hợp AI tư vấn sản phẩm và thanh toán trực tuyến.

## Front-end

Mã nguồn Front-end React.js + Vite được đóng gói tại `Frontend/NovaMart_Frontend_GitHub.zip`.

### Cách sử dụng

1. Tải file ZIP trong thư mục `Frontend/`.
2. Giải nén vào máy.
3. Mở thư mục `NovaMart_Frontend` trong VS Code.
4. Chạy `npm install`.
5. Sao chép `.env.example` thành `.env`.
6. Chạy `npm run dev`.

## Công nghệ

- React 19, Vite 6, React Router, Zustand
- CSS3 responsive
- Chuẩn bị tích hợp Java Spring Boot REST API, MySQL và Google Gemini API

## Trạng thái

Đây là nền tảng Front-end có tương tác với dữ liệu demo. Backend Spring Boot, MySQL, Gemini API thật và cổng thanh toán thật chưa được tích hợp trong gói này.

Không đưa `.env` chứa bí mật, API key hoặc thông tin thanh toán lên GitHub.
